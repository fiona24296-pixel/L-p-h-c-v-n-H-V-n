# Lớp Văn Cô Hạ Vân

Web app (PWA) quản lý lớp dạy thêm Ngữ văn: điểm danh, nhận xét, học phí, phiếu báo gửi phụ huynh.

- Mục tiêu, công nghệ, quy ước, tiến độ: xem [CLAUDE.md](CLAUDE.md)
- Hướng dẫn tạo Firebase: [docs/01-tao-firebase.md](docs/01-tao-firebase.md)
- Hướng dẫn đưa app lên mạng (Vercel) + cài lên điện thoại: [docs/02-dua-app-len-mang.md](docs/02-dua-app-len-mang.md)

```bash
npm install
npm run lint && npm run typecheck && npm test && npm run build
```
